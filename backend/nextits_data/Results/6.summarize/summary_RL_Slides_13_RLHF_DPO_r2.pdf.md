**Overview:**  
이 문서는 언어 모델(LLM)의 인간 피드백을 기반으로 한 강화학습(RLHF)과 그를 단순화한 직접적 선호 최적화(DPO)에 대해 설명합니다. 특히 인간의 선호를 기반으로 모델을 개선하는 방법, 이를 위한 기술적 접근 방식, 그리고 DPO가 기존 RLHF보다 더 간단하고 안정적인 방법임을 강조합니다. 또한 모델의 사실성 문제를 해결하기 위한 AI 기반 피드백을 활용한 DPO 적용 사례도 제시합니다.

---

**Key Points:**  
- 언어 모델은 토큰 기반의 자동 회귀 모델로, 인간이 선호하는 응답을 학습하는 데 RLHF를 사용합니다.  
- RLHF는 인간이 두 응답 중 더 유용한 것을 선택하는 선호 데이터를 기반으로, 보상 모델을 학습하여 이를 기반으로 정책을 최적화합니다.  
- 그러나 PPO 기반의 RLHF는 구현 복잡성, 리소스 소요, 보상의 추가 자유도(스케일 변화)로 인해 불안정하고 비효율적입니다.  
- DPO는 이러한 문제를 해결하기 위해 보상 모델을 학습하지 않고, 선호 데이터를 직접 정책 업데이트로 변환합니다.  
- DPO는 보상 함수와 정책 사이의 이론적 대응 관계를 활용해, 선호 데이터를 정책 손실로 직접 변환하여 보상 모델 없이도 학습이 가능합니다.  
- DPO는 계산 비용이 낮고 안정적이며, RLHF와 동일한 목적을 달성합니다.  
- DPO를 사용해 모델의 사실성 문제를 해결할 수 있으며, 모델 출력에서 원소적 사실적 주장(atomic claims)을 추출하고 AI가 이를 검증해 사실성 점수를 계산함으로써 인간 피드백 없이 사실성 향상을 가능하게 합니다.  
- DPO는 일반적인 NLP 문제(예: 사실성, 다양성, 윤리적 행동)에 적용 가능하며, AI 기반 피드백을 통한 자동 선호 생성이 핵심입니다.

---

**Conclusion/Implications:**  
RLHF는 언어 모델을 인간의 선호에 맞게 조정하는 데 효과적이지만, 실현에 있어 복잡하고 불안정합니다. DPO는 이 문제를 해결하여 보상 모델 없이도 선호 데이터를 직접 정책에 반영할 수 있도록 하며, 더 간단하고 효율적인 학습 방법을 제공합니다. 특히 사실성 문제를 해결하기 위해 인간 피드백 대신 AI 기반 자동 검증을 활용한 DPO는 모델의 신뢰성 향상에 중요한 역할을 할 수 있습니다. 따라서 DPO는 미래의 언어 모델 개선 및 실제 응용에서 핵심 기술로 자리 잡을 전망입니다.

- "Humans prefer 1.3B RLHF’d model to 175B SFT model" → 인간이 1.3B 파라미터 모델을 더 선호함.  
- DPO는 "RL training loop를 제거하고, 선호 비교를 정책 업데이트로 직접 변환"함.  
- "Standard RLHF doesn't solve the problem, possibly because humans struggle to ascertain factuality when giving preferences" → 인간이 사실성 판단을 어렵게 느끼므로 RLHF만으로는 사실성 향상이 어려움.  
- "DPO improves factuality through automated preference generation" → AI가 자동으로 사실성 판단을 수행하여 DPO를 통해 사실성 향상 가능.

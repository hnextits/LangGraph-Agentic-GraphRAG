# NextITS LLM 프로젝트

## 프로젝트 개요

NextITS LLM은 RAG(Retrieval-Augmented Generation) 기반의 지능형 문서 검색 및 질의응답 시스템입니다. 텍스트와 이미지를 모두 처리할 수 있는 멀티모달 AI 시스템으로, 웹 크롤링, 문서 처리, 임베딩 생성, 벡터 검색, 그리고 LLM 기반 답변 생성까지의 전체 파이프라인을 제공합니다.

## 주요 기능

- **멀티모달 RAG 시스템**: 텍스트와 이미지를 동시에 처리하는 통합 검색 시스템
- **웹 크롤링 및 문서 처리**: Google 검색 결과 크롤링 및 자동 문서 처리
- **지능형 문서 분석**: OCR, 레이아웃 분석, 시맨틱 청킹을 통한 문서 구조화
- **벡터 검색**: FAISS 기반 고성능 벡터 검색 엔진
- **실시간 질의응답**: FastAPI 기반 RESTful API 서버
- **현대적 웹 인터페이스**: Next.js + TypeScript 기반 반응형 프론트엔드

## 시스템 아키텍처

```
nextitslm/

│   ├── notebooklm/         # RAG 시스템 핵심 모듈
│   ├── nextits_data/       # 데이터 처리 파이프라인
```

## 백엔드 구조 상세

### 1. 메인 애플리케이션 (`main.py`)
- **FastAPI 서버**: 비동기 웹 서버 프레임워크
- **CORS 미들웨어**: 크로스 오리진 요청 처리
- **RAG 파이프라인 초기화**: 서버 시작 시 RAG 시스템 자동 로드
- **API 라우터 통합**: 모든 엔드포인트를 중앙에서 관리

### 2. RAG 시스템 (`notebooklm/`)

#### 핵심 컴포넌트
- **`rag_pipeline.py`**: RAG 시스템의 메인 오케스트레이터
  - 질의 라우팅, 검색, 답변 생성, 평가의 전체 파이프라인 관리
  - 텍스트/이미지 검색 결과 통합 및 base64 이미지 변환
  - 피드백 루프 및 답변 정제 기능

- **`shared_embedding.py`**: 공유 임베딩 모델 (싱글톤 패턴)
  - 텍스트와 이미지 검색에서 동일한 임베딩 모델 공유로 메모리 효율성 극대화
  - Qwen 모델 기반 고품질 임베딩 생성
  - GPU 메모리 사용량 모니터링 및 최적화

- **`router.py`**: 지능형 질의 라우팅
  - 질의 유형 분석 및 적절한 검색기 선택
  - 텍스트/이미지 검색기 병렬 실행

- **`generator.py`**: LLM 기반 답변 생성
  - 검색된 컨텍스트를 활용한 정확한 답변 생성
  - 프롬프트 엔지니어링 및 응답 품질 최적화

- **`evaluator.py`**: 답변 품질 평가
  - 생성된 답변의 품질 자동 평가
  - 피드백 기반 답변 개선

- **`refiner.py`**: 답변 정제
  - 생성된 답변의 품질 향상 및 일관성 보장

#### 검색 시스템
- **텍스트 검색** (`rag_text/`): FAISS 기반 시맨틱 검색
- **이미지 검색** (`rag_image/`): 이미지 임베딩 기반 유사도 검색
- **병렬 검색** (`parallel_search.py`): 다중 검색기 동시 실행

#### 설정 관리 (`config.py`)
- **모델 설정**: 임베딩 모델, 생성 모델 설정
- **경로 설정**: 데이터, 인덱스, 캐시 경로 관리
- **성능 튜닝**: 배치 크기, 디바이스 설정 등

### 3. 데이터 처리 파이프라인 (`nextits_data/`)

#### 파이프라인 구조 (`pipe/`)
- **`pipeline_text.py`**: 텍스트 문서 처리 파이프라인
  - 레이아웃 JSON 파일 처리
  - 텍스트 블록 정렬 및 구조화
  - 마크다운 변환 및 시맨틱 청킹

- **`pipeline_image.py`**: 이미지 문서 처리 파이프라인
  - 이미지 OCR 및 레이아웃 분석
  - 이미지 임베딩 생성 및 인덱싱

#### 처리 단계
1. **문서 업로드**: 다양한 형식의 문서 지원 (PDF, 이미지 등)
2. **OCR 처리**: 텍스트 추출 및 레이아웃 분석
3. **구조화**: 텍스트 블록 정렬 및 의미 단위 분할
4. **임베딩 생성**: 텍스트/이미지 임베딩 벡터 생성
5. **인덱싱**: FAISS 벡터 인덱스 구축

### 4. API 엔드포인트 (`api/`)

#### 주요 엔드포인트
- **`POST /search`**: 웹 검색 수행
- **`POST /add_document_from_search`**: 검색 결과에서 문서 추가
- **`POST /upload`**: 파일 업로드 및 처리
- **`POST /v1/chat`**: RAG 기반 질의응답
- **`POST /search_and_summarize`**: 검색 및 요약 (LLM 없이)
- **`GET /task_status/{task_id}`**: 비동기 작업 상태 확인
- **`GET /files`**: 문서 목록 조회
- **`GET /file/{filename}`**: 문서 내용 조회

#### 비동기 처리
- **백그라운드 작업**: 파일 처리, 인덱싱 등 시간이 오래 걸리는 작업
- **작업 상태 추적**: 실시간 진행 상황 모니터링
- **오류 처리**: 견고한 예외 처리 및 로깅

### 5. 웹 크롤링 (`search_test/`)
- **Google 검색 API**: 검색 결과 수집
- **웹 페이지 크롤링**: 검색 결과 페이지 내용 추출
- **콘텐츠 정제**: HTML 파싱 및 텍스트 추출
- **마크다운 변환**: 구조화된 문서 형태로 저장

## 프론트엔드 구조 (`frontend/`)

### 기술 스택
- **Next.js 14**: React 기반 풀스택 프레임워크

- **작업 상태 모니터링**: 비동기 작업 진행 상황 표시

## 설치 및 실행

### 백엔드 설정

1. **의존성 설치**
```bash
cd backend
pip install -r requirements.txt
```

2. **환경 변수 설정**
```bash
# .env 파일 생성
cp .env.sample .env
# 필요한 환경 변수 설정 (API 키, 모델 경로 등)
```

3. **서버 실행**
```bash
python main.py
```

### 프론트엔드 설정

1. **의존성 설치**
```bash
cd frontend
npm install
```

2. **개발 서버 실행**
```bash
npm run dev
```

3. **프로덕션 빌드**
```bash
npm run build
npm start
```
